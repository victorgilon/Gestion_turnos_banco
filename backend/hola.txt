CONFIGURACIÓN DEL PROYECTO NODE.JS - MICROSERVICIOS (GESTIÓN DE TURNOS)

=====================================================
1. INICIALIZAR PROYECTO NODE
=====================================================
Este comando crea el archivo package.json del proyecto:

npm init -y


=====================================================
2. DEPENDENCIAS PRINCIPALES DEL BACKEND
=====================================================
Instalar todas las dependencias principales en un solo comando:

npm i express bcryptjs cors dotenv jsonwebtoken mongoose morgan helmet


Descripción de cada módulo:

- express:
  Framework de Node.js para crear el servidor y definir rutas API.

- bcryptjs:
  Permite cifrar contraseñas antes de guardarlas en la base de datos.

- cors:
  Habilita la comunicación entre el backend y otros servidores o frontend.

- dotenv:
  Permite usar variables de entorno mediante un archivo .env.

- jsonwebtoken:
  Implementa autenticación basada en tokens JWT.

- mongoose:
  Librería para conectar y manipular datos en MongoDB.

- morgan:
  Muestra en consola las peticiones HTTP que llegan al servidor.

- helmet:
  Añade capas de seguridad a través de cabeceras HTTP.


=====================================================
3. HERRAMIENTAS DE DESARROLLO Y BABEL
=====================================================
Babel es un transpilador que convierte JavaScript moderno (ES6+)
en código compatible con versiones antiguas de Node.js.

Instalación de Babel y herramientas de desarrollo:

npm i @babel/core @babel/cli @babel/node @babel/preset-env nodemon -D


Descripción:

- @babel/core:
  Núcleo principal de Babel.

- @babel/cli:
  Permite ejecutar Babel desde la terminal.

- @babel/node:
  Ejecuta código moderno directamente en Node.js.

- @babel/preset-env:
  Permite usar características modernas de JavaScript (ES6+).

- nodemon:
  Escucha cambios en el código y reinicia automáticamente el servidor.


=====================================================
4. CONFIGURACIÓN POR MICROSERVICIOS
=====================================================
El proyecto está dividido en dos microservicios:

- auth-service  -> Servicio de autenticación (registro, login, JWT)
- turno-service -> Servicio para la gestión de turnos


=====================================================
5. CONFIGURACIÓN AUTH-SERVICE
=====================================================

1. Ir al directorio del servicio:
cd backend/services/auth-service

2. Inicializar proyecto:
npm init -y

3. Instalar dependencias principales:
npm i express bcryptjs cors dotenv jsonwebtoken mongoose

4. Instalar dependencia de desarrollo:
npm install -D nodemon

5. Compilar (si se usa Babel):
npm run build


=====================================================
6. CONFIGURACIÓN TURNO-SERVICE
=====================================================

1. Ir al directorio del servicio:
cd backend/services/turno-service

2. Inicializar proyecto:
npm init -y

3. Instalar dependencias:
npm i express bcryptjs cors dotenv jsonwebtoken mongoose morgan

4. Instalar herramientas de desarrollo:
npm i @babel/core @babel/cli @babel/node @babel/preset-env nodemon -D

5. Compilar (si se usa Babel):
npm run build


=====================================================
7. NAVEGACIÓN A CARPETAS SRC
=====================================================

cd backend/services/auth-service/src
cd backend/services/turno-service/src


=====================================================
8. RESUMEN ARQUITECTÓNICO DEL SISTEMA
=====================================================

El sistema de gestión de turnos está basado en una arquitectura
de microservicios:

- auth-service:
  Maneja registro de usuarios, login y generación de tokens JWT.

- turno-service:
  Administra la creación y gestión de turnos del banco.

- MongoDB Atlas:
  Base de datos centralizada para almacenar la información.

- JWT:
  Permite la autenticación y comunicación segura entre servicios.


=====================================================
9. RECOMENDACIÓN (BUENA PRÁCTICA)
=====================================================
Para evitar instalar dependencias una por una, se recomienda:

npm i express bcryptjs cors dotenv jsonwebtoken mongoose morgan helmet
npm i -D nodemon @babel/core @babel/cli @babel/node @babel/preset-env
