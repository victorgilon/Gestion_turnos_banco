
#Arquitectura del Sistema: gestion de turnos de bancos

##Problema que resuelve

1. ¿Qué problema resuelve el sistema?
   El sistema resuelve el problema de la mala organización en la atención, reduciendo el tiempo de espera y haciendo que el proceso de atención sea más ordenado
2. ¿Quién lo usará?
  El sistema sería utilizado por el personal encargado del banco para organizar y controlar los turnos, y principalmente por los clientes que necesitan ser atendidos.
3. ¿Qué pasaría si no existiera?
   Si no existiera un sistema de gestión de turnos, el banco tendría desorden en la atención, largas filas y confusión sobre quién sigue. Esto podría generar discusiones entre clientes
